# Pitch deck source

Source of the PortfolioIQ pitch deck (23 slides), published at
https://claude.ai/artifact/Xq8SFHVSKqGkcyeZdHwqQJ

- `deck.json`: slide order
- `slides/*.html`: one file per slide, speaker notes in each `<aside>`

Screenshots in the slides are hosted with the published deck (`/_blob/...` paths),
so open the link above to see the rendered deck. Edit the deck through Claude by
pointing it at that link.
